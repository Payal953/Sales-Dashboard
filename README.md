# Multi-Year-Sales-Dashboard

##  Project Overview

This Power BI project analyzes multi-year sales data to identify sales trends, profit performance, and business insights.

##  Tools Used

- Power BI
- DAX
- Data Analysis
- Data Visualization

##  Dashboard Features

- Year-wise sales analysis
- Monthly sales trends
- Profit analysis
- Regional performance
- Interactive filters and slicers

##  Objective

The objective of this project is to analyze sales data and provide meaningful insights through an interactive Power BI dashboard.

## HR Analytics Dashboard

### Project Overview

This project is an HR Analytics Dashboard created using Power BI. It helps analyze employee attrition, departments, salary slabs, and employee demographics.

### Tools Used

* Power BI
* DAX
* Data Visualization
* Data Analysis

### Key KPIs

* Total Employees
* Active Employees
* Attrition Count
* Attrition Rate
* Average Age
* Average Experience

### Dashboard Features

* Attrition by Department
* Attrition by Salary Slab
* Attrition by Gender
* Age Group Distribution
* Job Role and Job Satisfaction Analysis
* Department-wise Employee Count

### Project Objective

To analyze employee data and understand attrition patterns using interactive Power BI visualizations.

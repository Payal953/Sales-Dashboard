# Multi-Year-Sales-Dashboard

##  Project Overview

This Power BI project analyzes multi-year sales data to identify sales trends, profit performance, and business insights.

##  Tools Used

- Power BI
- DAX
- Data Analysis
- Data Visualization

##  Dashboard Features

- Year-wise sales analysis
- Monthly sales trends
- Profit analysis
- Regional performance
- Interactive filters and slicers

##  Objective

The objective of this project is to analyze sales data and provide meaningful insights through an interactive Power BI dashboard.
